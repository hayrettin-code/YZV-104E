# 🚀 YZV-104E: C Programming

This repository contains my term projects and programming assignments for the **YZV-104E** course at Istanbul Technical University. 

## 📂 Project Overview
This collection showcases my progression from foundational syntax and iterative control loops to advanced pointer arithmetic, dynamic memory allocation, structured file I/O operations, and engineering problem-solving.

### 🔄 Fundamental Logic & Loops
* **[Loops & Functions](loops-and-functions/)**: Advanced iterative logic, modular functional design, and recursive algorithm implementation ranging from mathematical sequences to ASCII histograms.
* **[Arrays & Matrices](arrays-and-matrices/)**: Statistical data analysis, variance/standard deviation computations, and memory-efficient array manipulation.

### 📍 Advanced Systems Programming
* **[Pointers & Memory](pointers-and-memory/):** Systems-level programming utilizing pointer arithmetic, manual heap memory management (`malloc`/`realloc`/`free`), and dynamic resource allocation.
* **[File Operations](file-operations/):** Implementation of persistent data storage systems using binary and text-based file I/O streams with random-access positioning.
* **[Cramer Evolution](cramer-evolution/):** An incremental engineering showcase demonstrating the evolution of a computational solver from a basic static script to a robust, file-driven system.

## 🛠️ Technical Skills
Throughout these projects, I have developed expertise in:
* **Language Standards:** C (ISO/IEC 9899 standard) and GCC compiler workflows.
* **Memory Management:** Heap allocation, pointer arithmetic, and manual resource lifecycle tracking.
* **System Design:** Implementing modular, structured (`struct`), and file-persistent application patterns.
