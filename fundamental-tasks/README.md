# 🧩 Fundamental Programming Tasks (C)

This directory contains a collection of foundational C programming tasks. These exercises focus on mastering control flow, decision-making algorithms, and input/output handling.

## 📝 About the Tasks
These programs were developed to practice core logical constructs, including `if-else` structures, `switch-case` statements, and mathematical formula implementation.

**Key Concepts Applied:**
* **Conditional Logic:** Complex nested `if` statements used for grading systems and triangular geometry calculations.
* **Flow Control:** Utilizing `switch` statements for menu-driven applications and classification logic.
* **Mathematical Modeling:** Implementing custom pricing, eligibility, and scoring algorithms.

## 📂 Included Programs
* `number_classify.c`: Categorizes input numbers as positive, negative, or zero using combined `switch` and `if-else` logic.
* `calc.c`: Basic arithmetic operations and absolute difference calculation between two numbers.
* `temp_classify.c`: Temperature classification logic (Freezing, Cold, Normal, Hot).
* `triangle_check.c`: Geometric triangle validation and classification (Equilateral, Isosceles, Scalene, or Invalid).
* `atm_simulation.c`: A simple bank balance management system with deposit and withdrawal validation.
* `shipping_cost.c`: Logistics cost assessment based on package weight and shipping distance thresholds.
* `service_calc.c`: Multi-zone pricing system with dynamic discount calculations based on service hours.
* `grading_system.c`: Comprehensive academic grading logic featuring midterm/final/makeup exam evaluation and honor status.
* `scholarship_eval.c`: Academic scholarship evaluation algorithm based on GPA, household income, research score, and volunteer work.
* `support_eval.c`: Social support eligibility scoring program based on income, household size, elderly care, and utility usage.
* `career_eval.c`: Career track and industry readiness evaluator based on student GPA or professional work experience.

## 🛠️ Technologies Used
* **Language:** C (ISO/IEC 9899 standard)
* **Compiler:** GCC (GNU Compiler Collection)
* **Paradigm:** Procedural Programming
