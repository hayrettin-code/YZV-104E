# 🔄 Loops & Functions: Algorithmic Logic (C)

This directory contains advanced C programming tasks that go beyond basic decision-making. These exercises focus on **iterative logic** (loops), **modular programming** (functions), and **recursive algorithm design**.

## 📝 About the Tasks
These programs demonstrate the ability to decompose complex problems into reusable functions and efficient control structures.

**Key Concepts Applied:**
* **Iterative Structures:** Mastering `for`, `while`, and `do-while` loops to handle repetitive calculations and pattern generation.
* **Modular Design:** Developing custom functions to break down logic, improve readability, and ensure code reusability.
* **Recursion:** Implementing recursive functions for mathematical sequences and power calculations, showcasing an understanding of stack-based algorithmic logic.

## 📂 Included Programs
* `investment_calc.c`: Calculates and displays long-term investment growth using a `for` loop and function-based interest logic.
* `digit_sum.c`: Extracts and sums the digits of an integer using `do-while` iteration.
* `reverse_number.c`: Reverses the digits of an integer using a `while` loop.
* `star_triangle.c`: Implements nested `for` loops to generate dynamic star-based geometric patterns.
* `modular_patterns.c`: Utilizes modular functions to create symmetrical increase-decrease triangle patterns.
* `diamond_pattern.c`: Draws complex diamond shapes using specialized pyramid-building functions.
* `fibonacci_series.c`: Computes and prints the Fibonacci sequence using recursive function logic.
* `recursive_power.c`: Performs exponential calculations using a recursive algorithm.
* `armstrong.c`: Calculates and displays Armstrong numbers up to a given limit using nested loops and digit-extraction logic.
* `prime.c`: Evaluates prime numbers, computes the nth prime, and identifies the index of a given prime using boolean logic and loops.
* `dice.c`: Simulates dual-dice rolls using random number generation, computes statistical frequency distributions and percentages, and renders an ASCII histogram.
* `date_diff.c`: Calculates the exact number of days between two given dates, featuring leap year detection and modular date-to-total-day conversion logic.
## 🛠️ Technologies Used
* **Language:** C (ISO/IEC 9899 standard)
* **Compiler:** GCC (GNU Compiler Collection)
* **Design Pattern:** Functional and Iterative Procedural Programming
